# Junior Developer Requirements

What the requirements for AI Native positions consist of. Each area is a separate document.

## Project context

All requirements reflect the projects where these positions open: legacy systems with 10+ years of history, running in production with millions of users, signed SLAs, and a real cost of failure. Around the code there are several vendors and teams, and changes must be agreed with them. Writing code is only part of the job. Understanding the requirements, breaking nothing, and taking the change through the whole process matter just as much.

- [SDLC](./sdlc.md) — the development lifecycle: from a requirement to production
- [AI SDLC](./ai-sdlc.md) — how AI is built into the development cycle: the agent, context, specs, control, cost
