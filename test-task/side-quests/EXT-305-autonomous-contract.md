# EXT-305 — Автономный прогон по контракту (после BEVN-203)
> Optional side quest · both tracks · не входит в основной маршрут
> Rules: [ASSIGNMENT.md](../README.md) · Quest map: [side-quests/README.md](README.md)

**Зачем:** чем дольше агент работает без надзора, тем меньше двусмысленности можно себе позволить. Пока вы сидите рядом, вы бесплатно делаете невидимую работу: замечаете, что агент ушёл не туда, и правите на ходу. Эта миссия — почувствовать, что происходит, когда эту работу никто не делает.
**Что тренирует:** написание полного контракта задачи (не только «что», но и бюджет, валидация, политика отказа); честную приёмку по заранее записанным критериям.
**Реальный юзкейс:** ночные автономные прогоны формализуют задачу контрактом из восьми полей (Objective · Inputs · Tools · Constraints · DoD · Validation · Budget · Failure Policy); классический анти-пример — «Improve our API» против «проанализировать обработку ошибок в 15 эндпоинтах, без изменений в проде, бюджет $2, эскалация после 2 попыток».
**Задача:** возьмите мини-фичу вне основного маршрута: *«кнопка Register Now не должна показываться на завершённых и отменённых конференциях»*. До запуска напишите полный контракт по восьми полям. Запустите агента и **не вмешивайтесь**: правки только через стоп и новый контракт. Примите или отклоните результат строго по записанному DoD.
**DoD:**
- [ ] `docs/contract-ext-305.md` написан до первой команды агенту (видно по коммитам)
- [ ] Прогон без вмешательств (каждое вмешательство, если было, зафиксировано в devlog как дефект контракта)
- [ ] Вердикт по DoD + разбор: какие поля контракта оказались недоспецифицированы
