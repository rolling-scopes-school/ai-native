# BEVN-001: Codebase mapping

> Phase 0: Discovery | Both tracks | Free-form
>
> Rules and route: [README.md](../README.md)

Explore the backend and document its architecture. Map the project structure, the responsibilities of Controllers, Services, Models, and Data, and the relationships between entities. Add an entity relationship diagram and document the request flow from HTTP request to database and back.

The result should let a new team member understand the architecture without first reading the source code.

## Definition of done

- [ ] Create an entity relationship diagram using draw.io, Mermaid, plain ASCII, or another clear format
- [ ] Add a responsibility table mapping Controllers, Services, and Models/Data to their roles
- [ ] Document the end-to-end request flow for at least three endpoints
- [ ] Save the result as `docs/architecture.md` in the project root
